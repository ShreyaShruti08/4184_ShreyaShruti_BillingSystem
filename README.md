# Grocery Billing System

## Description
This is a Java Swing based desktop application used to generate grocery bills.
It contains folders/ packages such as gui,model,service,util and main.

## Features
- Add and remove items
- GST calculation
- Save and load bills
- User-friendly interface

## How to Run
1. Download GroceryBilling.jar
2. Run using:
   java -jar GroceryBilling.jar
